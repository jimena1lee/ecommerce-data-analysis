Problem

문제 — 왜 이런 사람이 필요한가

BPO는 MD의 현업 언어를 개발자의 논리 언어로 번역하는 자리입니다. AI를 다루는 BPO는 있어도, MD로 8년을 직접 운영해본 BPO는 드뭅니다.

Solution

해결책 — 내가 가진 것

상품·프로모션·파트너 온보딩을 8년간 현업에서 직접 운영했고, Microsoft AI School에서 그 경험을 실제 동작하는 AI 서비스(QuoPilot·TerryPiQ)로 설계·구현했습니다. 현업의 언어와 개발의 언어, 그 사이를 번역하는 사람입니다.

Key Result

핵심 지표 — 증거

아이프라임 TF에서 입점 업체 수 목표 미달 상황을 3단계에 걸쳐 재진단했습니다.

9월 물류센터가 배포한 안내자료를 그대로 전달했지만 오히려 입점 영업이 위축됐습니다.
10월 MD 관점으로 자료를 재구성해 배포했지만 개선은 미미했고, MD들의 "배송비를 어떻게 산출하는지 모르겠다"는 피드백에서 진짜 문제가 이해 부족이 아니라 계산 도구의 부재임을 파악했습니다.
11월 비용을 자동 산출하는 시뮬레이터를 제작·배포하자 실적이 반등했고, 이후에도 소극적인 팀(홈앤리빙·패션레저·디지털)을 직접 찾아가 설명회를 진행해 입점 업체 수를 50개에서 120개까지 끌어올렸습니다.
📈 입점 업체 수 50개 → 120개 — 계산 도구 부재를 정확히 짚어낸 3단계 재진단의 결과입니다.

이 반등을 만든 실제 도구 — Qxpress 파트너 물류비 계산기

파트너가 상품 정보만 넣으면 자재비·입고비·배송비가 자동 산출되도록, 실제 단가표를 그대로 반영해 만든 온보딩 도구입니다. 아래에서 값을 바꿔가며 직접 계산해 볼 수 있습니다.

Differentiator

차별점 — 남과 다른 점

MD 경력 8년 생활·주방·펫·식품·패션 5개 카테고리를 상품기획부터 판매·정산까지 직접 운영 — '8년'이라는 숫자가 아니라 그 폭이 차별점입니다.
TerryPiQ(#잘케어하기) 헬스를 취미로 하다 생활체육지도사 2급을 취득했고, 이 관심사가 통증 부위·사진 기반 3D 테이핑 가이드 서비스 기획으로 이어졌습니다. 프로젝트 주제 선택 자체가 원래 관심사에서 출발했다는 점이 올리브베러의 '잘케어하기' 축과의 연결에 진짜 설득력을 줍니다.
