어디에 몰려 있는지를 보면 배분 문제가 드러난다. 의류(상의·하의·아우터)는 SKU 의 33.3%를 쓰면서 리뷰는 7.7%다. 반대로 실내화·학용품은 SKU 1.6%로 리뷰의 36.9%를 만든다.

2막 · 무엇이 변수인가

품목이 아니라 어떻게 파느냐가 갈랐다. 가격대와 배송타입으로 카탈로그를 네 칸으로 나누면 순서가 깨끗하게 정렬된다.

두 변수 모두 유효하지만 크기가 다르다. 배송타입을 바꿨을 때가 38배(저가) · 18배(고가), 가격대를 바꿨을 때가 7.5배(샛별) · 3.6배(판매자)다. 배송타입이 1차 변수다.

같은 품목, 다른 배송타입

"그 품목이 원래 잘 팔려서"라는 설명은 성립하지 않는다. 같은 품목 안에서 배송타입만 다른 쌍이 있기 때문이다. 특히 학용품은 SKU 수가 10개 대 11개로 거의 같은데 리뷰밀도가 31배 차이난다.

부록 · 방법론과 한계

카테고리 172(키즈웨어)와 919017(유아동패션)의 전 상품을 목록 API 로 수집한 뒤 상세 API 로 리뷰수를 재확인했다. 스냅샷은 2026-07-28이며 3,640 SKU 다.

  • 리뷰수는 판매량의 대리지표다. 노출기간·판매기간을 보정하지 않아 신상품에 불리하다. 순위를 판매량 순위로 읽으면 안 된다.
  • 목록 API 의 리뷰수에 결함이 있다. 리뷰가 적은 상품을 0 으로 반환한다. 목록에서 0 이던 3,596건을 상세 API 로 재확인해 555건을 보정했고, 총 리뷰수가 1,420 → 2,498건으로 늘었다. 이 문서의 모든 수치는 보정 후 값이다.
  • 평점은 쓰지 않았다. 컬리 API 가 rating/score/star 를 제공하지 않아 평점 컬럼이 전 행 비어 있다. 이 분석은 평점에 의존하지 않는다.
  • 브랜드명은 상품명의 [브랜드] 접두사에서 추출했다(커버리지 100%). 표본 20건을 상세 API 의 brand_info 와 대조해 17건 일치, 1건 표기차, 2건은 API 에만 브랜드가 없었다.
  • 172 와 919017 은 별개 매장으로 봐야 한다. 브랜드 교집합 0개(자카드 0.0000), 상품ID 교집합 0건이다. 172 는 level 1 독립 트리, 919017 은 level 2 로 분류 체계 자체가 다르다.
  • '기타' 1,718건은 분류 실패가 아니다. 12개 주요 분류에 속하지 않는 품목이며 한복·파티용품 등이 여기 들어간다. 다만 '미상' 402건은 영문 모델명 위주로, 키워드 분류의 한계에 해당한다.
